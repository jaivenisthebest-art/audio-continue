Audio Continue — Browser-only demo

This runs entirely in your browser — no server or Termux needed. It will:

  • Load an MP3/MP4/ WAV file from your phone.
  • Extract the last few seconds as a "seed".
  • Loop and pitch-shift the seed to create an extended audio clip.
  • Let you download the resulting WAV file.

Notes: This demo does not embed a synthesized voice continuation into the downloadable file because browser TTS can't be captured reliably across mobile browsers. You can use the built-in Speak button to hear a continuation live, or record the output with a screen/audio recorder if you need a file.

How to use

  1. Tap Choose file and pick the audio clip on your phone (3–15s recommended).
  2. Adjust seed length and output length, then Process.
  3. When finished, use the Download link to save the WAV to your phone.
  4. To hear a spoken continuation in the browser, edit the text and press Speak.
